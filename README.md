## What is HookTunnel?

HookTunnel helps developers capture, inspect, debug, and replay webhooks during development. Instead of deploying to test webhooks, point providers at your HookTunnel URL and see events instantly.

## Key Features

| Feature | Free | Pro |
|---------|------|-----|
| Webhook capture | 1 hook | 10 hooks |
| Event history | 24 hours | 30 days |
| Smart Search | Yes | Yes |
| Request replay | - | Yes |
| Payload storage | - | Yes |
